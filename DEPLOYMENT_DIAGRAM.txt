MDK-Predator Deployment Overview
=================================

OPTION 1: Download Pre-built (EASIEST)
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. Download from GitHub Releases                          │
│     https://github.com/limbo111111/mdk-predator/releases   │
│                                                             │
│     ↓                                                       │
│                                                             │
│  2. Get: mdk_predator.ppma                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘

OPTION 2: Build from Source
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. Clone repositories:                                     │
│     git clone https://github.com/limbo111111/mdk-predator  │
│     git clone https://github.com/portapack-mayhem/...      │
│                                                             │
│     ↓                                                       │
│                                                             │
│  2. Run build script:                                       │
│     ./scripts/build_portapack_app.sh -m /path/to/mayhem    │
│                                                             │
│     ↓                                                       │
│                                                             │
│  3. Get: build/portapack/mdk_predator.ppma                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘

DEPLOYMENT: SD Card Method (RECOMMENDED)
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Computer Side:                                             │
│  ┌──────────────────────┐                                  │
│  │ Format SD Card       │                                  │
│  │ as FAT32             │                                  │
│  └──────────┬───────────┘                                  │
│             │                                               │
│             ↓                                               │
│  ┌──────────────────────┐                                  │
│  │ Create Folders:      │                                  │
│  │   /APPS/             │                                  │
│  │   /MDK-PREDATOR/     │                                  │
│  └──────────┬───────────┘                                  │
│             │                                               │
│             ↓                                               │
│  ┌──────────────────────┐                                  │
│  │ Copy Files:          │                                  │
│  │   mdk_predator.ppma  │  →  /APPS/                      │
│  │   mdk_predator.conf  │  →  /MDK-PREDATOR/config/       │
│  └──────────┬───────────┘                                  │
│             │                                               │
│             ↓                                               │
│  ┌──────────────────────┐                                  │
│  │ Safely Eject         │                                  │
│  └──────────────────────┘                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘

TROUBLESHOOTING
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  App not in menu?                                           │
│    → Check file is in /APPS/ directory                     │
│    → Verify SD card is FAT32                               │
│    → Try different SD card                                  │
│                                                             │
│  "Init Failed" error?                                       │
│    → Check HackRF connection                               │
│    → Verify Mayhem-MDK module seated                       │
│    → Check power supply (5V, 2A min)                       │
│                                                             │
│  No signals detected?                                       │
│    → Verify correct antenna connected                      │
│    → Check frequency settings                              │
│    → Increase gain in config                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
